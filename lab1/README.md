# Лабораторная работа №1: Основы 3D-графики 

## Вариант 2 - Рамиил из Евангелиона, ой, то есть, Правильный октаэдр

### Задание:

Построить простой 3D-объект, вывести его на экран с помощью Vulkan и показать работу матриц проекции (перспективной и ортографической) и аффинных преобразований. Программа работает в реальном времени и управляется через интерфейс Dear ImGui.

### Дополнительные задания: 
1. Обеспечить переключение матрицы проекции (ортографическая и 
перспективная) в интерфейсе 
2. Добавить элементы интерфейса для изменения позиции, поворота и 
растяжения фигуры 
3. Добавить возможность движения и поворота фигуры по сложной траектории, 
сделать элемент интерфейса для паузы и воспроизведения “анимации”, а также 
возможность изменять скорость “анимации” и другие параметры траектории 
(например радиус траектории и др.) 
4. Добавить возможность изменять цвет фигуры с помощью элементов 
интерфейса (в ImGUI есть ColorEdit для этого) 
5. Назначить процедурно цвета для каждой вершины, например в 
зависимости от позиции вершин в локальной системе координат фигуры, 
тогда возможность изменять цвет с помощью элементов интерфейса 
будет умножать выбранный цвет на цвет вершин 
6. (На оценку 5) Подумать, как можно нарисовать больше одного объекта 
на сцене используя больше одного набора дескрипторов 
(VkDescriptorSet)

### Управление

Все параметры меняются в окне Octahedron:


Camera — тип проекции, угол обзора (FOV), расстояние до камеры.
Animation — пауза, скорость, радиус траектории.
Object 1 / Object 2 — позиция, поворот (в градусах), масштаб, цвет, флажок Animate.


Поля с числами можно менять перетаскиванием мыши или двойным кликом с вводом значения.

### Требования
Windows 10/11
Visual Studio 2022 с рабочей нагрузкой «Разработка классических приложений на C++»
Vulkan SDK (нужен компилятор шейдеров glslc)
CMake (входит в Visual Studio) и интернет при первой настройке проекта
Видеокарта с поддержкой Vulkan

### Сборка и запуск
1) Через Visual Studio


Откройте Visual Studio и выберите Файл → Открыть → Папка, укажите папку lab1.
Дождитесь окончания настройки CMake (окно «Вывод», источник «CMake»). При первом запуске библиотеки скачиваются и собираются, это может занять несколько минут.
Если нужно начать с чистого листа: Проект - Удалить кэш и перенастроить.
Выберите Сборка - Собрать всё.
Выберите цель запуска vulkan-starter-app.exe и нажмите F5.

2) Через командную строку

Откройте «Developer PowerShell for VS» (или обычную консоль с CMake) в папке lab1:

cmake --list-presets

cmake --preset <имя-пресета>

cmake --build <папка-сборки>

Имена пресетов указаны в файле CMakePresets.json. Собранный файл vulkan-starter-app.exe находится в папке сборки (например, build-debug).

Программа ищет скомпилированные шейдеры (*.spv) в папке shaders относительно рабочей папки, а также в ../shaders и build-debug/shaders, поэтому её можно запускать как из корня проекта, так и из папки сборки.

# Лабораторная работа №2: Камера и освещение

## Вариант 2 — Правильный октаэдр

### Задание

Реализовать камеру с возможностью перемещения и освещение по модели Блинна-Фонга с несколькими типами источников света (направленный, точечные, прожекторные). Объект — правильный октаэдр из лабораторной работы №1. Программа работает в реальном времени, все параметры камеры, источников и материалов меняются через Dear ImGui.

### Что сделано

**Базовое задание**
- камера: позиция, поворот (yaw / pitch), угол обзора (FOV), ближняя и дальняя плоскости, перспективная и ортографическая проекция (из лабы 1). Матрица вида строится как обратная к матрице «модели» камеры;
- у вершин есть атрибут нормали, нормали генерируются процедурно (`generateFlatNormals` в `geometry.hpp`: нормаль грани = нормированное векторное произведение двух рёбер треугольника);
- модель Блинна-Фонга во фрагментном шейдере (`shaders/lit.frag`) по формуле из лекции 4: `[albedo + specular * (n·h)^shininess] * (n·l) * E`;
- направленный источник (направление, цвет, интенсивность, вкл/выкл) и рассеянный свет (цвет, интенсивность);
- параметры материала каждого объекта: альбедо, цвет блика, коэффициент блеска (+ умножение на процедурные цвета вершин из лабы 1).

**Дополнительные задания**
1. Два набора дескрипторов: `set = 0` — сцена (uniform-буфер с `view_projection`, позицией камеры, направленным и рассеянным светом, количеством источников + два storage-буфера с массивами источников), `set = 1` — модель (матрица модели, матрица нормалей, материал). Набор сцены привязывается один раз за кадр, набор модели — для каждого объекта.
2. Массив точечных источников в storage-буфере (`binding = 1`), затухание по закону обратных квадратов, добавление/удаление/изменение источников в интерфейсе. Источники можно заставить вращаться вокруг сцены.
3. Массив прожекторов в storage-буфере (`binding = 2`), затухание по закону обратных квадратов, мягкие края между внутренним и внешним углом (плавный переход `smoothstep`), добавление/удаление/изменение в интерфейсе. Прожектор можно прикрепить к камере («фонарик»).
4. Визуализация источников (включается флажком *Show light gizmos*): яркая сфера цвета источника для точечных и прожекторных источников, для прожекторов — конус белыми линиями (внешний угол, серым — внутренний, и ось направления). Визуализация рисуется отдельным конвейером без освещения.

Storage-буферы растут автоматически при добавлении источников, поэтому максимальное количество источников в шейдере не задаётся.

### Требования
- Windows 10/11
- Visual Studio 2022 с рабочей нагрузкой «Разработка классических приложений на C++»
- Vulkan SDK (нужен компилятор шейдеров glslc)
- CMake (входит в Visual Studio) и интернет при первой настройке проекта
- Видеокарта с поддержкой Vulkan

### Сборка и запуск

**Через Visual Studio**
1. Файл → Открыть → Папка, выбрать папку `lab2`.
2. Дождаться окончания настройки CMake (окно «Вывод», источник «CMake»).
3. Сборка → Собрать всё.
4. Выбрать цель запуска `lab2.exe` и нажать F5.

**Через командную строку** (Developer PowerShell for VS в папке `lab2`):
```
cmake --preset debug
cmake --build build-debug
```

Шейдеры компилируются автоматически при сборке (`*.spv` появляются в папке `shaders`). Программа ищет их в `shaders/`, `../shaders/` и `build-debug/shaders/`, поэтому её можно запускать из корня проекта или из папки сборки.
